Only use it for accounts that cannot be settled the normal way - someone who died, moved away and cannot be reached, or who cannot be invoiced at all. {% if easyverein_active %} Everyone else should be invoiced via EasyVerein instead. {% else %} Everyone else should get a normal invoice instead. {% endif %}

What will happen

  1. All of {{ object.display_name }}'s unbilled purchases and payments are put on a new invoice, exactly like a normal invoicing run would.
  2. A correction payment of {{ settlement|currency }} is booked on that invoice. It is not real money - it only brings the account balance to exactly {{ 0|currency }}.
  3. No email is sent and {% if easyverein_active %} nothing is transferred to EasyVerein. {% else %} no bill is handed to anyone. {% endif %} Nobody is going to pay this - the bar absorbs it.

Afterwards

The correction payment stays in the payment list together with your reason, so the write-off remains traceable later on.
